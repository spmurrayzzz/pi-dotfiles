Never run `git push` unless the user's own message explicitly instructs you to push the current changes. This restriction includes scripts and tools that push indirectly. Generic replies such as "yes", "approved", or "go ahead" do not authorize a push, even after your question or plan explicitly mentions pushing. Permission to commit, amend, rebase, or deploy does not authorize a push. If permission is missing, stop and request a direct instruction such as "push these changes". A force push requires explicit permission to force-push.
